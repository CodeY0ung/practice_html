1. '== '연산자

Java에서 `==` 연산자는 두 값이 같은지를 비교할 때 사용하는 연산자이다.
하지만 비교 대상이 기본 자료형인지 참조 자료형인지에 따라 비교하는 대상이 달라진다.

기본 자료형의 경우

`int`, `double`, `char`, `boolean`과 같은 기본 자료형에서는 `==`가 실제 저장된 값을 비교한다.

int a = 10;
int b = 10;

System.out.println(a == b);

실행 결과:

true

`a`와 `b`에는 모두 `10`이라는 값이 저장되어 있기 때문에 `true`가 출력된다. 즉, 기본 자료형에서는 다음과 같이 이해하면 된다.

a == b
↓
a의 값과 b의 값을 비교

참조 자료형의 경우

객체를 사용하는 참조 자료형에서는 의미가 달라진다.

Person p1 = new Person("Kim"); Person p2 = new Person("Kim");

`p1`과 `p2`는 내부에 같은 `"Kim"`이라는 값을 가지고 있지만 서로 다른 객체이다.

System.out.println(p1 == p2);

실행 결과:

false

그 이유는 참조 자료형에서 `==`는 객체 내부의 값을 비교하는 것이 아니라 **두 변수가 같은 객체를 참조하고 있는지**를 비교하기 때문이다.

메모리 구조를 단순하게 표현하면 다음과 같다. ```text p1 ──────> Person 객체 A name = "Kim" p2 ──────> Person 객체 B name = "Kim" ``` 두 객체의 `name` 값은 같지만 `p1`과 `p2`가 가리키는 객체 자체가 다르기 때문에 다음 비교는 `false`가 된다. ```java p1 == p2 ``` 반대로 다음과 같은 경우를 보자. ```java Person p1 = new Person("Kim"); Person p2 = p1; ``` 메모리 구조는 다음과 같다. ```text p1 ─────┐ ├────> Person 객체 A p2 ─────┘ name = "Kim" ``` `p1`과 `p2`가 동일한 객체를 참조하고 있기 때문에 다음 결과는 `true`이다. ```java System.out.println(p1 == p2); ``` ```text true ``` 따라서 참조 자료형에서 `==`는 다음과 같이 이해할 수 있다. ```text p1 == p2 ↓ 두 변수가 같은 객체를 가리키는가? ``` 객체가 가지고 있는 실제 내용을 비교하려면 `==`가 아니라 `equals()` 메서드를 사용해야 한다.
